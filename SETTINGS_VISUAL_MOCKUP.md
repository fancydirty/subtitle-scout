## 🎨 设计规格

### 颜色系统
```
卡片背景：    ╔══╗  bg-card (#16181f)
卡片边框：    ║  ║  border-border (hairline)
文字主色：    Text  text-foreground (#e6e8ec)
文字辅助：    hint  text-muted-foreground (#6b7280)
状态-成功：   [✓]   text-green-500 (#28bf5c)
状态-警告：   [⚠️]  text-yellow-500 (#f5a623)
状态-可选：   badge text-muted
```

### Spacing 规范
```
卡片内边距：   p-6     (24px)
卡片间距：     gap-6   (24px)
字段间距：     gap-4   (16px)
小元素间距：   gap-2   (8px)
Section 间距： gap-8   (32px)
```

### 组件高度
```
Input:      h-10    (40px)
Button-sm:  h-8     (32px)
Button-md:  h-10    (40px)
Badge:      h-5     (20px)
```

## 📱 响应式行为

### Desktop (> 1024px)
- Content max-width: 4xl (896px)
- 卡片单列布局
- Sidebar 固定 260px

### Tablet (768px - 1024px)
- Content 占满减去 padding
- 卡片保持单列
- 输入框宽度自适应

### Mobile (< 768px)
- Sidebar 折叠成汉堡菜单
- 卡片 full-width
- 按钮 full-width
- 复制按钮改为图标

## 🔄 状态系统

### Badge 变体
```
✓ 已配置    success   绿色 bg-green-500/10 text-green-500
⚠️ 未配置    warning   黄色 bg-yellow-500/10 text-yellow-500
可选        secondary 灰色 bg-secondary text-muted-foreground
运行中      info      蓝色 bg-blue-500/10 text-blue-500
```

### 测试按钮状态
```
默认：  [测试连接]              variant="secondary"
加载：  [⏳ 测试中...]          disabled loading
成功：  [✓ 连接成功]  (2s)      variant="success"
失败：  [✗ 连接失败]  (toast)   variant="destructive"
```

## 🎯 关键交互

### 1. 添加媒体目录
```
点击 [📁 添加目录] 
  ↓
Dialog Modal 打开
  ├─ 目录浏览器（树形）
  ├─ 面包屑导航
  ├─ [取消] [添加此目录]
  ↓
选择后关闭 modal
  ↓
卡片显示已添加列表
```

### 2. 测试连接流程
```
点击 [测试连接]
  ↓
按钮变为 [⏳ 测试中...] (disabled)
  ↓
API 请求
  ├─ 成功 → 按钮文字变 [✓ 连接成功] (2s) → 恢复
  └─ 失败 → Toast 显示错误 → 恢复
```

### 3. 高级设置展开
```
默认：▸ 高级设置 (Accordion collapsed)
点击：▾ 高级设置 (Accordion expanded)
  ↓
显示环境变量表格：
  LLM_BASE_URL          https://token-plan-sgp...
  LLM_MODEL             mimo-v2.5
  DASHBOARD_PORT        8099
  TMDB_API_KEY          ey•••AY4
  ... (只读列表)
```

## 📐 Grid 布局细节

```tsx
// 单列表单
<div className="space-y-4">
  <FormField />  // 每个字段独占一行
</div>

// 双列表单（宽屏）
<div className="grid grid-cols-1 md:grid-cols-2 gap-4">
  <FormField />
  <FormField />
</div>
```

### 按钮组布局
```tsx
// 左对齐
<div className="flex gap-2">
  <Button>主要</Button>
  <Button variant="outline">次要</Button>
</div>

// 右对齐
<div className="flex justify-end gap-2">
  <Button>保存</Button>
</div>

// 全宽（移动端）
<Button className="w-full sm:w-auto">测试连接</Button>
```

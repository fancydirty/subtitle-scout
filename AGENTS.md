# AGENTS.md

Subtitle Scout is a self-hosted subtitle automation daemon: it scans media library
roots, identifies files via TMDB, finds/verifies/installs matching subtitles, and ships
with a web dashboard (default port 8099).

- **If the user asks you to deploy, configure, or troubleshoot a Subtitle Scout
  instance**, read and follow `skills/subtitle-scout-wizard/SKILL.md` — it covers the
  full deployment/configuration/debugging workflow and the container's HTTP API.
- For a product overview and quick start, see `README.md`.
- For working on the codebase itself, see `CONTRIBUTING.md`.
